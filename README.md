# بوابة مكتب سامح عمار للمحاماة

منصة خاصة لإدارة القضايا والعملاء ومهام المكتب ومستنداته. الدخول مخصص للحسابات المعتمدة للمكتب، ولا تتوفر خاصية إنشاء حساب من الواجهة.

**المحامي سامح عمار — تطوير المهندس عمرو جمال عوض**

## استخدام المنصة

تدعم الواجهة العربية واتجاه RTL، مع التبديل بين المظهر الفاتح والداكن. يُحفظ اختيار المظهر على الجهاز، ويُستخدم إعداد النظام عند عدم وجود اختيار محفوظ. تعتمد الخطوط على خطوط النظام العربية.

بعد تسجيل الدخول تتوفر صفحة رئيسية، وتقويم للجلسات، وبحث شامل في القضايا والعملاء وبيانات التواصل وأسماء المستندات (Ctrl+K)، وتقارير إحصائية قابلة للطباعة أو التصدير بصيغة CSV. قد تحتوي الملفات والتقارير المصدّرة بيانات سرية؛ احفظها في مكان آمن.

يمكن حذف القضية من جدول القضايا أو سجلها؛ يتطلب الحذف تأكيدًا ويزيل المتابعات والمهام والحركات المالية والمرفقات المرتبطة بها، مع الإبقاء على ملف العميل. لا يمكن التراجع عن الحذف.

يمكن إرفاق عدة مستندات بكل قضية وتصنيف كل ملف. الأنواع المسموحة PDF وWord والصور وTXT، بحد أقصى 10 ميجابايت لكل ملف. تشمل المنصة سجل متابعة القضايا، والمهام، ومواعيد الجلسات، ومتابعة الأتعاب والمصروفات، وقوالب مسودات قابلة للتنزيل والطباعة.

يوفر زر المساعد إجابات محلية عن استخدام المنصة، ويرسل الأسئلة القانونية العامة إلى نموذج NVIDIA Kimi عبر Firebase Cloud Functions. لا يطلع المساعد على ملفات المكتب ولا يحفظ نصوص الأسئلة في Firestore، لكن نص السؤال يُرسل إلى مزود خارجي؛ تجنب كتابة الأسماء وأرقام القضايا وأي بيانات سرية. الاستخدام محدود بـ25 سؤالًا لكل حساب في اليوم. الإجابات للتوعية وليست استشارة قانونية أو بديلًا عن محامٍ مختص. صُممت نافذة المساعد لتلائم شاشات الهاتف ولوحة المفاتيح الآمنة.

## إعداد المساعد الذكي

يتطلب تشغيل المساعد تفعيل خطة Firebase Blaze وربط وسيلة دفع، وقد تترتب رسوم على استخدام وظائف Firebase أو مزود النموذج. اضبط تنبيهات الميزانية ومراقبة الاستخدام قبل تفعيله.

1. إذا سبق مشاركة مفتاح NVIDIA في محادثة أو مكان عام، ألغِه وأنشئ مفتاحًا جديدًا.
2. من مجلد المشروع، شغّل `firebase functions:secrets:set NVIDIA_API_KEY --project samehamar`، وأدخل المفتاح الجديد في مطالبة الطرفية السرية فقط. لا تضعه في `index.html` أو `firebase-config.js` أو ملفات `.env`، ولا ترسله في المحادثات.
3. انشر الوظيفة عبر `firebase deploy --only functions:askLegalAssistant --project samehamar`.
4. انشر تحديث الواجهة عبر `firebase deploy --only hosting --project samehamar`.

تتطلب وظيفة المساعد تسجيل دخول، وتحد الاستخدام إلى 25 سؤالًا لكل حساب يوميًا مع مهلة قصيرة بين الطلبات. تخزن Firestore عداد الاستخدام فقط؛ لا تسجل الوظيفة نص السؤال أو الإجابة.

تعرض قائمة الجرس الجلسات والمهام القادمة خلال أسبوع. عند السماح بإشعارات المتصفح، تظهر تذكيرات محلية قبل الموعد بيوم أو ساعة أثناء بقاء الموقع مفتوحًا؛ لا تصل هذه التذكيرات إذا أُغلق الموقع أو المتصفح.

يستخرج البحث بالمستندات النص من ملفات TXT وPDF النصية وDOCX على جهاز المستخدم. لا يدعم OCR، لذلك لا يبحث داخل الصور أو ملفات PDF الممسوحة ضوئيًا أو ملفات DOC القديمة. تُحتفظ نتائج النص في ذاكرة الجلسة فقط وتمسح عند تسجيل الخروج.

## تثبيت الموقع على الهاتف

يعمل التثبيت على عنوان HTTPS أو localhost فقط؛ فتح `index.html` مباشرة كملف لا يتيح تثبيت الموقع.

- **Android / Chrome:** استخدم زر «تثبيت التطبيق» إذا ظهر، أو قائمة Chrome ثم «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **iPhone / iPad:** افتح الموقع في Safari، واضغط «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

تظهر خيارات التثبيت بحسب دعم المتصفح وحالة تثبيت التطبيق.

## البيانات والخصوصية

الدخول مخصص لحساب المكتب المعتمد. استخدم كلمة مرور فريدة، ولا تشارك بيانات الدخول أو ملفات العملاء. ملفات النسخ الاحتياطية قد تحتوي بيانات سرية وغير مشفّرة؛ احفظها مؤقتًا في مكان آمن واحذفها بعد التحقق من الاستيراد.

إذا كانت لديك بيانات قديمة محفوظة على جهاز أو عنوان سابق، نزّل نسخة احتياطية قبل الانتقال؛ تخزين المتصفح منفصل بين العناوين. بعد تسجيل الدخول استخدم «استيراد نسخة قديمة» لنقل البيانات.
